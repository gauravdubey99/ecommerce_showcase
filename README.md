# ecommerce_showcase

Tech Stack being used
1. Frontend
TypeScript: A strongly-typed superset of JavaScript for building scalable and maintainable frontend applications.

React: A popular JavaScript library for building user interfaces.

HTML/CSS: For structuring and styling the frontend.

UI Libraries: We’ll use a library like Material-UI or Tailwind CSS for pre-built components and styling.

Axios: For making HTTP requests from the frontend to the backend.

2. Backend
Python: The primary programming language for backend development.

FastAPI: A modern, fast (high-performance) web framework for building APIs with Python.

SQLAlchemy: An ORM (Object-Relational Mapping) tool for interacting with PostgreSQL.

PostgreSQL: A powerful, open-source relational database for storing structured data (e.g., users, products, orders).

JWT (JSON Web Tokens): For user authentication and authorization.

Stripe/Razorpay: For payment gateway integration.

3. Database
PostgreSQL: The primary database for storing structured data.

MongoDB (optional): A NoSQL database for flexible data storage (e.g., product reviews, logs).

4. DevOps and Deployment
Git: For version control.

GitHub Actions: For CI/CD (Continuous Integration and Deployment).

Docker (optional): For containerizing the application.

AWS: For deploying the application (e.g., EC2 for backend, RDS for PostgreSQL, S3 for file storage).

5. Testing and Tools
Postman: For testing APIs.

Pytest: For writing unit and integration tests in Python.

Jest/React Testing Library: For testing React components.

Swagger UI: For API documentation (automatically provided by FastAPI).
